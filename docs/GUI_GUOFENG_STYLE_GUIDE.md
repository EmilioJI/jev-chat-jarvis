# 国风 UI 设计规范

适用分支：`feature/guofeng-ui`

这套视觉不是在原 Material 蓝色主题上简单换色，而是统一为“宣纸 + 黛青 + 朱砂 + 铜金”的轻国风产品语言。目标是：有国风识别度，但不牺牲信息密度、可读性和聊天场景下的快速扫读。

## 设计原则

1. **宣纸为底，不用纯白**  
   主背景使用暖纸色，卡片使用稍亮的纸白；避免冷灰蓝背景。

2. **黛青负责交互，朱砂只做强调**  
   主按钮、开启态、标题使用黛青；删除、危险和印章使用朱砂。朱砂不能大面积铺满。

3. **标题有书卷感，正文保持现代可读**  
   页面标题、卡片标题、主 CTA 可使用系统 serif；正文、参数、状态仍用 sans-serif，避免“全页面书法体”。

4. **水墨是背景，不抢信息**  
   水墨山形、竹影、日晕均为低透明度程序绘制，不使用大图做 UI 背景，不干扰文字。

5. **卡片边界靠纸色和细描边，不靠重阴影**  
   圆角 14–24dp；1dp 暖灰/浅玉描边；Elevation 控制在 0–2dp。

6. **悬浮窗必须比首页更克制**  
   聊天场景优先可读性，使用暖纸半透明背景 + 黛青交互，不放复杂水墨装饰。

## 页面结构

### 首页

- 顶部：产品名 + 副标题 + 朱砂“知言”印章
- 就绪卡：无障碍 / 悬浮窗 / 密钥三项状态
- 启用准备：三个权限卡
- 常用入口：知识库与联系人、接口与分析
- 底部：单一主 CTA “开始辅助 / 辅助已开启”

首页不是设置项堆叠页。高频任务必须在一屏内理解。

### 设置页

- 使用同一宣纸背景
- 长表单按“接口 / 分析 / 外观”等 section 分组
- provider pill 使用黛青选中态、铜金弱选中背景
- 输入框使用暖纸灰，不使用冷灰 `#F3F4F6`
- 测试按钮使用描边玉色风格

### 知识库与联系人

- “笔记 / 联系人”使用书签式 pill
- 内容卡片保持较高密度，避免大面积装饰
- 删除与清空历史始终使用朱砂色
- 对话框仍优先可读性，不强行加入装饰

### 悬浮分析面板

- 悬浮球：深黛青
- 面板：暖纸半透明
- 头部：`Jev · 对话研判`
- 最佳回复：浅玉背景
- 复制：纸白描边
- 填入：深黛青实心
- 危险等级：仅徽章使用动态绿 / 金 / 朱砂

## 字体

不捆绑第三方字体文件。

- 标题：系统 `SERIF`
- 正文：系统 `SANS_SERIF`
- 参数、URL、模型名：继续保持系统 sans-serif

原因：避免 APK 增大、字体授权问题和不同 Android ROM 的字形兼容风险。

## 背景实现

`InkPaperDrawable.kt` 使用程序绘制：

- 暖纸渐变
- 低透明日晕
- 远近两层山形
- 薄雾线
- 左下竹影
- 确定性的纸张微颗粒

不使用随机数，因此每次 redraw 视觉稳定，也不会造成动画式闪烁。

## 禁止项

后续页面不要重新引入：

- `#3A7AFE` 作为主色
- 冷灰 `#F2F3F5 / #F3F4F6` 作为大面积背景
- 纯黑 `#000000` 主文字
- 大面积朱砂按钮
- 重阴影 / 高 elevation
- 每个组件都加祥云、竹子、山水等装饰
- 第三方未授权中文字体

## 验收

新增或修改 UI 时至少检查：

- 页面是否仍可在小屏设备单手扫读
- 输入框、URL、API Key 是否清晰
- 浅色卡片与宣纸背景对比是否足够
- 危险 / 删除是否不会与普通强调混淆
- 悬浮面板是否仍能看清底下聊天
- 不因国风装饰降低功能可发现性
